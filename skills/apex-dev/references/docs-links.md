# Where to look things up

Use the version selector on each site to match your APEX and database version.

- Oracle APEX documentation: https://docs.oracle.com/en/database/oracle/apex/
- APEX API reference (APEX_UTIL, APEX_PAGE, APEX_JSON ...): in the same documentation set, "API Reference"
- APEX data dictionary views (`apex_application_page_regions` etc.): in the "Application Express Views" part of the documentation
- Oracle Database SQL Language Reference and PL/SQL Language Reference: https://docs.oracle.com/en/database/oracle/oracle-database/
- SQLcl documentation, including the `apex` command and the MCP server: https://docs.oracle.com/en/database/oracle/sqlcl/
- Oracle APEX community and blog posts are useful for patterns but check the version they were written for.

Rule of thumb: when this skill's notes and the official documentation disagree, trust what the validator or the database actually does, then fix the notes.
